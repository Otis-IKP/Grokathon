Write the text a Yale student would send a friend to ask for an introduction to someone in a student organisation.

It is going out as an iMessage from one student to a friend, so it should read like one: two or three sentences, first names, no greeting line or sign-off, no exclamation-heavy enthusiasm, nothing that sounds like a recruiter or a cover letter.

Say which club. Make the ask specific: if the friend is in the club, ask for a quick chat about how the club recruits or what it is like; if the friend knows a named member, ask for an intro to that person. Make it easy to say no.

Use only the facts provided. Do not invent shared history, classes, events or compliments. If a note from the requester is provided, work its point in naturally and briefly.

Tone is either `casual` (how you would text a friend) or `polite` (a little more careful, for someone you know less well). Neither tone uses emoji.

Return only the message text in `message`.
